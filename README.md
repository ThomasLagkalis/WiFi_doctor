## Installation

To install all the requirements, run:

```sh
pip install -r requirements.txt
```

## Usage

To run the project, follow these steps:

1. Open `wifi_doctor.py` and uncomment the pickup you want to use.
2. Run the script:

   ```sh
   python wifi_doctor.py
   ```

3. Select an option from the prompt:
   - `1` - Density Analysis
   - `2` - Performance Analysis

**Note:** For performance analysis, use `HowIWiFi_PCAP.pcap`.

## Project Structure

### Directories

- **captures/** - Contains all the `.pcap` files.
- **plots/** - Stores all the figures generated by running WiFi Doctor.

### Python Files

- **`parser.py`** - The parser module.
  - Contains the `Parser` class and the function `parse_pcap()`, which parses a `.pcap` file into a list of dictionaries, each entry containing relevant packet data.

- **`data_monitor.py`** - The monitoring module.
  - Handles both density and performance analysis.
  - Contains the `DataMonitor` class.
  - Implements `_Re_mapping(mcs_index, phy_type, bandwidth, spatial_streams, short_gi)`, which maps configuration settings to a data rate value (refer to the report for details).
  - `get_performance_data()` extracts key performance metrics like throughput and mean data rate from parsed capture data.
  - `get_density_data()` extracts density analysis metrics.

- **`analyzer.py`** - The performance analyzer.
  - Contains the `Analyzer` class and the function `performance_analysis(data)`, which processes performance data and groups it by key metrics before displaying results.

- **`visualizer.py`** - The visualization module.
  - Contains the `Visualizer` class.
  - Provides functions to generate plots and histograms, applying rolling averages where necessary for smoother visual representation.

- **`wifi_doctor.py`** - The main driver script.
